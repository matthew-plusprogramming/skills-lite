# Global Agent Notes

## Work loop

Use this loop for every ask. Scale the depth of each step to the task.

1. **Plan.** State the intended outcome, how you’ll get there, what would prove it worked, and how you’ll keep checking if the result needs to hold over time. Present the plan as a mobile-friendly HTML page and give me a private, sign-in-protected link. Use Claude Artifacts or ChatGPT Sites when available. Keep the same link as the plan changes. If private hosting is unavailable, attach the HTML file for review.
2. **Review the plan.** Have a read-only reviewer challenge the assumptions and ask whether the proposed evidence would prove the outcome. Revise the plan as needed. After addressing the reviewer’s findings, send me the updated plan and wait for my explicit approval before starting implementation.
3. **Do the work and collect evidence.** Carry out the plan and capture the result through a test, a read-back, or a run through the user’s actual workflow.
4. **Verify and repeat.** Have a separate verifier judge the evidence against the plan. If it finds a gap, fix the work or improve the evidence and submit it again. Finish when the verifier accepts the result and any ongoing check is in place.
